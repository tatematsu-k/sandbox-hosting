1. 概要

Claude Code や Slack から生成した HTML を、社内IPからのみ閲覧できる sandbox 領域に ワンコマンドで公開するためのツールです。アップロードした HTML は {timestamp}_{username} 形式の自動パス、または {slug} 形式の 固定パスで配信されます。

用途: 内部レビュー用のモック共有・PoC・記事下書き・お試しのウェブUIなど。
顧客向けの本番配信、認証が必要な業務情報、公開予定の制作物には使わない。

2. コマンド一覧

コマンド用途備考
uploadHTMLまたはディレクトリを公開ディレクトリは自動でzipに固める
list自分の公開サイト一覧TTL・状態を一覧
activateTTL切れサイトを再公開TTLは公開日から+90日リセット
deleteサイト完全削除blob/metaを物理削除

Claude Code から

# 単一HTMLを公開
./skills/sandbox-upload/scripts/upload.sh ./report.html

# ディレクトリ（index.html必須）
./skills/sandbox-upload/scripts/upload.sh ./build

# 固定slug指定（上書き）
./skills/sandbox-upload/scripts/upload.sh --path demo-foo ./report.html

# 一覧 / 再アクティブ / 削除
./skills/sandbox-upload/scripts/upload.sh list
./skills/sandbox-upload/scripts/upload.sh activate <path>
./skills/sandbox-upload/scripts/upload.sh delete   <path>

Slack から

/sandbox <html>
/sandbox demo-foo <html>
/sandbox https://files.slack.com/.../site.zip

4. 信頼境界・既知リスク

  • OK 公開URLは Terraform変数 allowed_ips のIPからのみ CloudFront Function が許可する
  • OK S3 バケットは private + OAC で CloudFront 経由のみアクセス可
  • OK Slack 経路はHMAC署名検証 (5分以内)、Claude Code 経路はBearer token
  • OK 秘密情報は SSM Parameter Store (SecureString / KMS暗号化) で管理
  • Caveat API Gateway の rate limit は throttling burst 50 / rate 25 のデフォルト。WAFは未導入
詳細な評価は docs/architecture-review.md 参照。WAF rate limit ルールが次フェーズの対応候補。

5. 運用ランブック

初回セットアップ（運用者）

aws configure
cd terraform && cp terraform.tfvars.example terraform.tfvars  # 編集
cd ..
./scripts/setup-aws.sh        # ビルド → terraform apply

クライアント初期設定（各利用者）

./scripts/setup-client.sh        # ~/.config/sandbox-hosting/env を生成
./scripts/healthcheck.sh         # 公開→閲覧の往復チェック

TTL切れに気付いたとき

./skills/sandbox-upload/scripts/upload.sh list
./skills/sandbox-upload/scripts/upload.sh activate <path>

誤って上げてしまったとき

./skills/sandbox-upload/scripts/upload.sh delete <path>

トークン漏洩時

  1. 漏洩したユーザーのトークンを失効 
    ./scripts/manage-tokens.sh revoke <username>
  2. 必要なら新しいトークンを発行し、本人に配布 
    ./scripts/manage-tokens.sh issue <username>
  3. 不正アップロード分は list scope=all で確認し delete
